# h

**кабинет медленного искусства**

Убежище для светского уединения. Одна комната, одно произведение, один час.

![Фасад](assets/facade-2x1.png)

**Живая версия:** **https://skrasin.github.io/gallery-ch/**

## Идея

Большой город производит одиночество с той же интенсивностью, с какой производит новые связи. Кабинет обращается к одиночеству, чтобы найти в нём уединение.

В плотной застройке мы концептуализируем потребность в дистанции. Место отстранения возвращает к традиционным павильонам для любования — ограниченным пространствам для созерцания на пейзажных маршрутах. Здесь роль проводника у природы забирает медленное искусство.

Ограничение становится формой заботы — и об искусстве, и о посетителе. Пространство сужено до одной комнаты, выбор до одного произведения. Взгляду не по чему скользить, и остаётся пространство для уединённого труда души.

## Имя

Основное имя — **кабинет медленного искусства**. Короткая форма — **h**, для знака, фавикона, корешка и малых форматов.

Оба написания строчными, всегда — даже в начале предложения. Не «КМИ», не «Кабинет», не «h.» с точкой.

В профиль буква читается как навес: вертикальная опора и свод над пустотой. Павильон для любования, уместившийся в один знак. Это не аббревиатура, расшифровывать её не нужно.

## Знак

  <source media="(prefers-color-scheme: dark)" srcset="assets/mark-full-white.svg">
  <img src="assets/mark-full.svg" alt="Знак: скобки, черта и точка" width="220">
</picture>

Скобки — комната, ограничение сделанное видимым. Черта — произведение на стене. Точка — посетитель. Расстояние между ними — дистанция, ради которой всё устроено.

| Параметр | Значение |
|---|---|
| Поле | `2u × 1u` (или `1u × 2u`) |
| Высота скобок и черты | `0.7u` |
| Толщина скобок | `u/20` — вдвое тоньше черты |
| Отводы скобок | `0.12u` внутрь поля |
| Толщина черты | `u/10` |
| Диаметр точки | `0.3u` |
| Дистанция черта → точка | `0.5u`, не меняется никогда |
| Положение черты | ось симметрии поля, левая половина пуста |
| Охранное поле | `0.5u` |
| Минимум | 40 px на экране, 12 мм в печати |

Толщина черты выведена, а не подобрана: при длине `0.7u` её площадь совпадает с площадью точки с точностью до процента.

**Редуцированный знак — это полный минус скобки.** Поле и все величины те же: комната исчезает, расстояние остаётся.

## Цвет

| | HEX | Роль | Доля |
|---|---|---|---|
| Стена | `#FFFFFF` | фон, тишина | 90% |
| Знак | `#000000` | знак, текст | 9% |
| Дерево | `#A78353` | акцент | 1% |

В тёмной теме: `#101010` / `#F2F0EC` / `#C9A16A`. Это не «ночной режим», а второе состояние кабинета — свет выключен, остались произведение и посетитель.

## Типографика

Helvetica Neue, одно семейство. **Light 300** — рабочее начертание. UltraLight 100 только для вордмарка от 120 px, Regular 400 для меток, Medium 500 для выделения. Bold, Black, Condensed и наклонные не используются.

Моноширинного начертания в семействе нет, и оно не нужно: цифры Helvetica табличные по построению.

## Что в репозитории

```
index.html                        полная дизайн-система, один самодостаточный файл
tokens/tokens.css                 токены для веба
tokens/tokens.json                токены для Figma Tokens / Style Dictionary
assets/mark-full.svg              знак, основная версия
assets/mark-full-vertical.svg     знак для узких форматов
assets/mark-reduced.svg           без скобок
assets/mark-reduced-vertical.svg  без скобок, вертикально
assets/mark-*-white.svg           те же четыре в инверсии
assets/facade.jpg                 исходный чертёж фасада
assets/facade-2x1.png             чертёж, скадрированный в поле знака 2:1
presentation/                     презентация — описывает версию «Ч», требует пересборки
```

`index.html` не тянет ни одного внешнего файла: стили, скрипт и чертёж встроены внутрь. Его можно открыть двойным кликом, отправить письмом или положить на любой хостинг.

## Как открыть локально

```bash
open index.html
```

## Как обновить

Дизайн-система — один файл. Правьте `index.html` и коммитьте:

```bash
git add -A && git commit -m "Правки в раздел «Знак»" && git push
```

GitHub Pages пересобирает страницу автоматически при каждом пуше в `main` — обычно за минуту.

Если меняете токены — правьте их и в `index.html` (раздел «Токены»), и в `tokens/`, чтобы документация не разошлась с файлами.
